# Checks (reference: what the editor looks for in a draft, by level of editing)

The `edit-drafts` skill loads this file under "Checking a draft". A check
names a thing the editor can find in the text; whether a claim is true or an
argument succeeds is NEVER a finding.

**The editor edits; it does not referee.** Whether the draft answers the
objections it should, engages the literature it should, or reads its sources
rightly is a reviewer's judgment, and NEVER a finding.

**The checks hold for any draft.** A journal's or a press's own rules are
checked only when the user gives them, under "Checking a draft against given
standards" of the skill.

## The levels

| Level | Looks at | Its checks |
| --- | --- | --- |
| structure | the draft's organisation: what each part does for the argument | "Structure" |
| line | the sentence and the paragraph: clarity, coherence, flow | "Line" |
| copy | correctness and consistency: usage, terms, citations, quotations, apparatus | "Copy", "Sources" |
| proof | a later version against an earlier check | "Proof" |

## What is never a finding

**A matter on which the guides to academic writing disagree is the user's
choice.** NEVER report one as a fault; report it only where the draft does it
two ways, as a question of which stands.

| Matter | Never reported as a fault |
| --- | --- |
| voice | a passive sentence, as such; the first person; "to be" as a main verb |
| hedging | a hedge that marks real uncertainty; a firm claim the draft argues for |
| signposting | how much the draft announces its own structure |
| length | a long sentence that parses; a long paragraph with one topic |
| usage | a split infinitive; a sentence that ends on a preposition; singular "they"; "which" in a restrictive clause; a contraction |
| difficulty | a hard idea or a complex argument, stated as plainly as it allows; a term of art |
| quotation | how much the draft quotes; where its quotation marks sit beside other punctuation |

## Structure

**Write a reverse outline first: for each paragraph, its topic and what it
does for the argument, in at most ten words each.** The outline is the
editor's working paper; deliver it only if the user asks.

| A finding is | Found by |
| --- | --- |
| a paragraph with no one topic, or whose function for the argument cannot be stated | the reverse outline |
| two paragraphs, or two sections, that make the same point | the reverse outline |
| a paragraph or a section that never says how it bears on the draft's question | the reverse outline |
| a new topic that first appears in the conclusion | the reverse outline |
| a passage that relies on a term, a distinction, or a result the draft introduces only later | the order of the outline |
| an exposition of a view that no later passage draws on | the outline against each exposition |
| a criticism of a view before any statement of what the view says | the order of the outline |
| a thesis that no sentence of the opening section states | the opening section |
| a thesis stated with one strength in the abstract, another in the introduction, and another in the conclusion | the three statements, set side by side |
| two positions that exclude each other, each endorsed in its own section | the draft's own endorsements, set side by side |
| a step the introduction promises that no section takes; a roadmap whose order the sections do not follow | each "I will", "I argue", "I show" of the introduction |
| an abstract that states what the draft does not argue | the abstract against the reverse outline |
| an enumeration that breaks: "first" with no "second", "on the other hand" with no "on the one hand", three reasons announced and another number given | each enumeration |
| an exposition of a source with no marker of where the report ends and the user's own claim begins | each paragraph that both reports and asserts |
| a view attributed to an author with no passage cited and no word that the attribution is the user's inference | each attribution |
| a question the draft raises and leaves open without saying that it leaves it open | each question raised |
| a quotation followed by no sentence saying what it shows; two quotations in a row | each quotation |
| an opening that speaks of the ages, of the topic's importance, or of what scholars have lately turned to, before the question; except a survey of a literature | the first paragraph |
| a passage that says the topic is difficult, complex, or controversial, and adds nothing | the opening and the conclusion |
| a dictionary's definition given as the authority for a philosophical term | each definition |
| a central claim or distinction stated in the abstract alone, with no case of it anywhere | each central claim |

## Line

| A finding is | Found by |
| --- | --- |
| a topic sentence that does not match its paragraph | each paragraph |
| a transition that asserts a link the text has not made | each "thus", "hence", "therefore", "it follows" |
| an inference whose middle step is unstated; a sentence that takes up nothing the sentences before it said | each inference; each sentence's opening |
| a sentence that carries two claims a reader could dispute apart | each long sentence |
| a subject parted from its verb by a long interruption | each sentence |
| a sentence whose new point sits in its middle, and which ends on what the reader already has | each sentence's close |
| an action carried by a noun and an empty verb: "conduct an analysis of", "give consideration to" | each "make", "give", "have", "take", "conduct" with a noun |
| a nominalisation or a passive that hides who holds or does what is reported | each report of a view |
| a noun that can be struck with no loss: "level", "framework", "context", "process", "issue", "perspective", "role" | each such noun |
| a technical term not defined where it first appears; an ordinary word used in a set sense without saying so | each term of art |
| one term under two senses in two passages; one thing under two terms | the term's occurrences, set side by side |
| a relational word with no complement: "relevant", "related", "similar", "different" | each such word |
| an identity asserted where a looser relation is meant: "is", "is the same as", "amounts to" | each such statement |
| a word mentioned without quotation marks; quotation marks about the user's own ordinary word, where a reader cannot tell whether the user endorses it | each word discussed as a word; each such pair of marks |
| an ambiguity of scope: the place of "only"; "not … because"; "all … are not"; "or" under "believes" or "knows" | each such pattern |
| a doubled modal: "must necessarily", "cannot possibly" | each modal |
| an evaluative modifier that presupposes the thesis before the draft argues it | modifiers in the premises |
| a citation standing where a sentence of reasoning is due | sentences that end an argument on a citation |
| "this" or "that" with no noun it names | each sentence-opening demonstrative |
| "the literature", "many scholars", "it is often argued" with no named work | each unspecific attribution |
| "must", "cannot", "demonstrates", "proves", "all", "never", "obviously" beside evidence the draft itself presents as partial | each strong modal, universal, and intensifier |
| more than two hedges in one paragraph, where the draft elsewhere asserts the same point plainly | hedges by paragraph |
| a question standing where the draft means an assertion; a run of questions the draft does not answer | each question |
| stacked negatives; a wordy frame: "the question as to whether", "it is the case that", "due to the fact that"; a redundant pair | each sentence |
| a parenthesis or an aside whose removal leaves no grammatical sentence | each parenthesis |
| a non-parallel series; a misplaced modifier; a string of four or more nouns; a run-on that chains claims with "and" | each sentence |
| an epithet for an author or a view in place of what is wrong with it; praise beyond the argument | each evaluative word about an author |

## Copy

| A finding is | Found by |
| --- | --- |
| a choice of style the draft makes two ways: spelling variant, serial comma, dash, ellipsis, number style, italics, quotation marks, capitalisation of a coined term or of headings, hyphenation of a compound, punctuation of a list, the pronoun for a person in general, a contraction | each choice, as the draft first makes it |
| a primary text cited in two forms in one draft; a text cited now in the original, now in translation, now in both | each primary text's citations, set side by side |
| a term the draft fixes, used later in another sense or under another word | each term, as the draft first fixes it |
| a name, a date, or a figure that differs from its earlier occurrence in the draft; a cited author's name or a title spelled otherwise than in the reference list | a list of names and a list of facts, kept while reading |
| figures that do not add up to the total the draft gives | each sum |
| an abbreviation used before it is defined; defined twice or two ways; written in two forms; defined and never used | each abbreviation |
| non-English matter with inconsistent italics, capitalisation, accents, or script | each non-English word and passage |
| a misspelling; a grammatical slip; a sentence that does not parse; a doubled word; a search-and-replace remnant | each sentence |
| a word of the user's trade used loosely: "imply" for "infer"; "refute" for "deny"; "valid", "sound", or "false" of what is no argument or of an argument; in philosophical prose, "begs the question" for "raises the question" | usage |
| a footnote mark without its footnote, or a footnote without its mark; a footnote that cannot be read on its own; note marks placed now before, now after the punctuation | the notes |
| a heading level skipped; a heading that does not name what its section holds; a cross-reference to a section, a note, a figure, or a page the draft lacks; a part named one way in the contents and another at its head | the headings and each cross-reference |
| a quotation mark or a bracket left open; nested quotation marks that do not alternate; a missing space before a parenthesis or after punctuation | each pair of marks |
| a hyphen in a page range; a page range elided inconsistently | each range |

## Sources

**Grade each claim about a source against the passage it cites, with one
verdict of the table.**

| Verdict | The cited passage |
| --- | --- |
| `supported` | states the claim |
| `partial` | states part of the claim, or states it of a narrower case |
| `distorted` | states something the claim oversimplifies, overgeneralises, or reverses |
| `unsupported` | does not state the claim, or is unrelated to it |
| `inaccessible` | could not be read: the work is not held, or the folio is not in the held copy |
| `not checked` | was not read in this check |

**A passage not found is `inaccessible`, NEVER `unsupported`.** Report the
count of each verdict, and name which claims were `not checked`.

| A finding is | Found by |
| --- | --- |
| a claim graded `partial`, `distorted`, or `unsupported` | the verdicts |
| a quotation `verify.py verify` does not confirm at the folio cited | `verify` |
| a spelling or a grammar slip inside a quotation, reported as the source's own or as the draft's | `verify`'s page text |
| a change inside a quotation that is not marked: a word added without square brackets, words left out without an ellipsis, emphasis added without saying so | the quotation against the page text |
| an omission or a cut that changes what the passage says | the quotation against the passage around it |
| an ellipsis that opens or closes a quotation plainly given as a fragment | each quotation |
| quoted words that do not fit the grammar of the sentence that holds them, and are not bracketed | each quotation run into a sentence |
| a quotation standing as a sentence of its own, with no words saying whose it is | each quotation |
| a reporting verb whose force is not the source's or not the draft's: "shows" of a claim the draft disputes, "claims" of one it relies on | each reporting verb |
| a paraphrase that keeps the source's sentences and changes words here and there; reported as close to the source, NEVER as plagiarism | each paraphrase of a held work against its passage |
| a quotation without a citation; a generalisation about a literature without a citation | each quotation and each generalisation |
| one citation closing a paragraph in which several sentences draw on the source | each paragraph that reports a source |
| a quotation of a primary text cited through a secondary work without "quoted in"; "quoted in" for a work the library holds | each citation's citekey against the work quoted |
| a translated quotation with no translator named and no general note on translations; a translation the user changed, not declared | each translated quotation |
| a citekey `citations` lists as not held; a citation without a locator where the sentence reports a passage or a view; a locator that is no folio of the held work | `citations` |
| a work cited that the reference list lacks; a work listed that the draft does not cite | the citations against the reference list |
| a work that appears only inside a cluster of citations and that no sentence discusses | each citation cluster |
| two systems of citation in one draft; an `ibid.` after a note that cites more than one work; one work under two short titles; a short title before the full reference | the notes, in order |
| a passage that repeats, word for word and over more than a sentence, a published piece of `writing/4 published/`, with no note saying so | the draft against the published pieces |

## Proof

**On a version cut after a check, grade each finding of that check.**

| Grade | The new version |
| --- | --- |
| `addressed` | no longer shows the finding |
| `partly addressed` | shows it in part |
| `not addressed` | shows it as before |
| `declined` | shows it as before, and the user said it stands; NEVER raise it again |
| `new problem` | shows a problem the fix introduced |

| A finding is | Found by |
| --- | --- |
| a change that answers no finding of the earlier check | the two versions, set side by side; read each such change as new text, under "Copy" |
| an editor's comment left in the text; a sentence amended halfway | the new version |
| text missing or repeated where a fix was made | each fix, with the sentences on either side |
| a note out of sequence, or a mark without its note, after an insertion or a deletion | the notes, in order |
| a cross-reference or a link that no longer resolves | each cross-reference |
| a further case of a kind of slip the earlier check found | the whole text, searched for the kind |

**Report what was checked, NEVER that the text is clean.** Make no finding of
style at the proof level unless the user asks for a full check.

## How a finding is worded

- **Raise a finding only if it needs raising.** A wording the editor would
  have chosen otherwise is no finding. Look up an unfamiliar word or usage
  before querying it.
- Address the text, never the user: "the paragraph asserts", never "you
  assert". Say what a reader will meet, not what the user did.
- Say where, by section and paragraph, quote the words, and say what and why.
  NEVER write "revise" or "unclear" alone.
- Where the sense is in doubt, give the two readings and ask which is meant.
  Allow that the editor has misread.
- If two passages disagree, quote both and ask which stands.
- If a sentence cannot be made clearer without deciding a question the draft
  leaves open, say which question, and propose no wording.
- State a change of the user's wording as a proposal with the wording it
  replaces. A change that could alter the meaning is always explained; a
  mechanical one is listed.
- Raise a recurring matter once, with its count and its first place.
- Keep a finding as long as it has to be, and no longer.

## What the report carries besides the findings

- **What was left.** Each kind of thing noticed and not reported, under "What
  is never a finding".
- **What was not checked.** Each level not run, each claim graded `not
  checked`, each work that was `inaccessible`.
