## Builds

- The audit workflow (U5–U8) in `all` mode with `loop` and `fix`, on each repo.
- Each repo's fixes land on its fix branch and reach `main` through one PR per
  repo.
- An `all` run exceeds one capped run: rotation covers the plane across runs,
  and the report states coverage by unit and by age.

VM. The PR body states the runs, the dispatches, and the tokens spent per repo.
