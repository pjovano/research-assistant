## Builds

| Command | Does |
| --- | --- |
| `bootstrap` | creates `~/.research-vault/venv` with `uv` and syncs `requirements.lock`; writes `machine.json` if absent; creates the inbox and the state directories; sets `core.hooksPath` to `.githooks` (X1); installs the health job through `Scheduler`; pulls the local models (the Ollama model, the citation parser, the tokenizer) |
| `bootstrap --no-jobs` | the same, without the jobs; the switch runs it at §6 step 4.4, and every test install runs it |
| `doctor` | one line per check, `ok` / `missing` / `failing` with the fix: Python and the venv; the lock in sync; the Zotero connector answers on `23119`; Better BibTeX answers; ZotMoov configured (the library path in its preferences); the Obsidian vault folder exists; pandoc, typst, ffmpeg, yt-dlp found |
| `doctor`, primary checks | the health and Remote Control jobs installed and loaded; no iCloud placeholder in the library or the inbox (P6+M4), which stands in for Optimize Mac Storage off |

`bootstrap` runs only from a terminal, never inside the agent's sandbox. The
Remote Control job is installed by the switch (§6 step 4.6), never by
`bootstrap`.

Not built: profiles, per-profile locks, adapter and API-key checks.
