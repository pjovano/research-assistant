worker, and workflow in the core, symlinked into `research-assistant`, the
shape spike item 3 used on `spike/probes`.

Two PRs: the core's first, then the domain's subtree add. The domain PR names
the core PR and merges after it.

## Spike findings that bind

- Item 3: the symlinks loaded in nested headless runs on Linux. A fresh cloud
  session started on such a branch, and macOS, were not tested.
- Item 6: `git subtree add`, `pull --squash`, and `split` work on git 2.43.
  The session's `push.negotiate=true` prints a harmless `fatal: expected
  'acknowledgments'` on a push to a file remote.
