## Builds

| Piece | Content |
| --- | --- |
| `.github/workflows/ci.yml` | a `macos-latest` job beside `ubuntu-latest` on every PR; both run the suite, ruff, and the audit linter |
| `tests/_support.py` | a `requires_platform` decorator for the platform-bound tests |
| Skips | the existing skips (typst, the HF model cache, the node runtime) stay skips on an absent tool |

The Mac is the only platform the setup runs on, so the macOS job is the CI run
that matters most. The repository is public, so GitHub charges no Actions
minutes for either job. The macOS job builds the venv from `requirements.lock`,
which resolves `ocrmac` and the MPS torch build on darwin; the PR reports that
job's wall time.
