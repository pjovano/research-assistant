## Builds

New sections of the core's general `clean-prose`, restating ASD-STE100's
writing rules in house form. No text is copied from the specification. There
is no general dictionary: the domain's `.claude/glossary.md` is the
technical-names list.

| Rule | Threshold |
| --- | --- |
| Sentence length by form | Command, Prohibition, Conditional ≤ 20 words; Definition, Invariant ≤ 25 |
| One instruction per sentence | one imperative or force word per main clause |
| Active voice for actions | no passive in a Command or a Conditional |
| Noun clusters | ≤ 3 nouns in a row; technical names exempt |
| Paragraph length | ≤ 6 sentences; a sequence of actions is numbered steps |
| One topic per paragraph | judgment |
| Condition before action | already in `clean-prose` |

Counting: a code span, a glossary term, and a table cell count as one word
each; a table cell's limit is its row's form.

**Ratchet.** The rules bind text written or changed after adoption. Existing
text keeps its findings, acknowledged by U3. The > 40-word tail is U2b. The
chat register (§9) stays out of the STE rules.
