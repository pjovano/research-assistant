## Builds

| Piece | Content |
| --- | --- |
| `tests/audit_bench/seeds.json` | one seed per defect class, `{id, check, class, target, mutation}`; the initial ~30 classes of the source plan, the recast-rationale tail and the cross-boundary repetition as negative seeds |
| `tests/audit_bench/plane/` | a small synthetic control plane, clean at rest, naming no domain |
| `audit.py bench build <dir>` | copies the plane into `<dir>` and applies every seed; prints the seed manifest |
| `audit.py bench score <dir> <findings.json>` | matches findings to seeds by check and `file:line` window; prints recall per check and per layer, and the unmatched findings |
| `tests/test_audit_bench.py` | the lint layer's recall on the seeds, deterministic |
| Root threading | `Baseline._present`, `FileMeasures._finding`, `Residue`, `AuditSet`'s baseline default, `audit.py`'s repository lookup, and `scope.py`'s root take the domain root, defaulting to the git top level of the working directory |

**Baseline measurement.** Run today's skill procedure once against the seeded
plane, as one agent, and record recall per check in the PR body. That number is
the floor every later audit item holds.
