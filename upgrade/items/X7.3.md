| Command | Does |
| --- | --- |

| `cutover.py switch` | §6 step 4: unload the old health and Remote Control jobs; move the old venv aside; apply `~/.claude/settings.json`; `bootstrap --no-jobs`; stop for the one interactive `claude remote-control` run in `~/Developer/agent-core` and the folder trust of `~/Developer/research-assistant`; install the new jobs through the core's `Scheduler`: `health.py install --apply` in `~/Developer/research-assistant`, `bin/remote_control.py install --apply` in `~/Developer/agent-core` |
| `cutover.py rollback` | reload the old jobs, restore the old venv, point the user at `~/Developer/research-tools` |
| Read-only form first | each command without `--apply` prints every step it would take and changes nothing |
| Runbook | `upgrade/switch.md`: §6 as numbered steps, each with its command, its check, and its rollback point |
