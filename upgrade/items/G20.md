## Spike findings that bind

| Finding | Consequence |
| --- | --- |
| Item 7: `denyRead` blocks a sandboxed Bash read of the folder and not the Read tool; a `Read(...)` deny rule blocks the Read tool | the generator writes both rules for every denied folder |
| Item 7: Grep and Glob untested; the docs apply Read rules to them as a best-effort attempt | Rehearsal: R-G20-3 checks both |
| Item 1: the sandbox is not enforced in a cloud session | no cloud PR can verify a sandbox rule; Rehearsal: R-G20-2, R-G20-3 |
| Item 2: a headless session in an untrusted workspace ignores `permissions.allow`; `permissions.deny` still applied | the read guard rests on deny rules, which hold in an untrusted workspace; an allow rule MUST NOT carry a guarantee |
