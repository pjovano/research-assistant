## Builds

- Read every acceptance row of the four source plans and of every item file.
- For each row, find the CI test that checks it on `main`, or its line in
  `rehearsal.md`.
- Each row with neither gets a test or a rehearsal line, in this PR.
- A row of a deferred item, or of a deferred part of a kept item (`PLAN.md`
  §3, "Deferred"), gets neither: the table lists it as deferred.
- The PR body carries the table: row, source, test or line.
